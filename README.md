# onboarding-app

Ausgeliefert über GitHub Pages unter https://app.tanjawissel.ch (DNS bei cyon: CNAME `app` → `tanjawissel.github.io.`).

- `index.html` – Platzhalter, bis das App-Gerüst mit Login steht
- `prototyp/` – Kopie von `Prototyp CRM/` (klickbar, Daten nur im Browser)
- `CNAME` – eigene Domain für GitHub Pages

Hier liegt nur Programmcode: keine Daten, keine geheimen Schlüssel. Anleitung: `../Hosting app.tanjawissel.ch - Anleitung.md`.
